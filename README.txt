OTR Freight LLC website (otruae.com)

Upload everything in this folder to the root of your web hosting (public_html / htdocs / GitHub Pages root).
- index.html carries the Google site verification meta tag in its <head>.
- Contact form opens the visitor's email app addressed to pramod@otruae.com.
  For a form that sends without an email app, connect a service such as Formspree and set it as the form action.
- CNAME is only for GitHub Pages; delete it on other hosts.
- After upload, submit https://otruae.com/sitemap.xml in Google Search Console.
